# Chart Analysis

한국·미국 주식 종목을 입력하면 TradingView 차트와 **일봉·주봉, MACD(6,19,9)·MACD(19,39,9), RSI, OBV, 추정 VRVP**을 보여주는 Python/Streamlit 웹앱입니다. 브라우저로 사용하며 자동 매매나 증권 계좌 연결은 하지 않습니다.

## 설치 없이 웹으로 사용하기

Streamlit Community Cloud에 이 저장소를 연결해 배포할 수 있습니다. 저장소는 `wagurano87/chart-analysis`, 브랜치는 `main`, 실행 파일은 `app.py`, Python은 `3.12`를 선택하세요. 계정 연결, 배포 후 확인 및 접근 설정은 [웹 배포 안내](DEPLOYMENT.md)를 따르세요. GitHub에 코드가 올라간 것과 웹서비스가 실제로 배포된 것은 별개입니다.

웹으로 배포하면 사용자가 올리는 CSV는 호스팅 서버로 전송됩니다. 민감한 자료는 업로드하지 마세요. 공유 전에 앱의 접근 범위를 확인하세요.

## Windows 설치·실행

Python 3.11 이상(`py` 실행기 포함)을 설치하고 저장소를 다운로드한 뒤 PowerShell에서 실행합니다.

```powershell
.\install.ps1
.\start.ps1
```

스크립트 실행 정책에 막히는 경우 현재 창에만 적용한 후 다시 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

시작 시 표시되는 로컬 주소를 본인 브라우저에서 여세요. 기본 포트는 8501이며 `Ctrl+C`로 종료합니다. `start.ps1`은 `127.0.0.1`에만 연결하므로 같은 PC에서 사용합니다.

### Linux / macOS

```bash
python -m venv .venv
```

## 사용법

1. 데이터 방식을 선택합니다: 온라인 시세, CSV 업로드, 가상 데이터 체험.
2. 시장과 종목을 입력합니다.
   - 한국: `005930`(삼성전자), `000660`(SK하이닉스), `247540`(에코프로비엠). KOSPI/KOSDAQ을 순서대로 조회합니다.
   - 미국: `AAPL`, `NVDA`, `MSFT`, `IBM`, `BRK.B` 등. TradingView용 거래소도 정확히 선택하세요. 예: IBM은 NYSE.
   - 회사명 검색은 아직 지원하지 않습니다.
3. **분석하기**를 누릅니다. 매도 검토 경고, MACD 변화, 거래량 배율, 이동평균과 차트가 표시됩니다.
4. 필요하면 분석 결과를 CSV로 다운로드합니다.

온라인 연결이 없어도 **가상 데이터 체험**으로 기능을 확인할 수 있습니다. 가상 데이터는 실제 종목 가격이 아닙니다. CSV는 동일한 종목의 다음 열을 가진 일봉 파일이어야 합니다.

```csv
Date,Open,High,Low,Close,Volume
2026-10-20,100,105,98,103,100000
2026-10-21,103,106,101,102,150000
```

위 예시는 형식 설명이며 실제 분석에는 **선택한 주기의 완료된 봉 최소 120개**가 필요합니다. 중복 날짜, 결측값, 음수 거래량, 올바르지 않은 OHLC는 거부합니다. 일관된 수정주가 기준의 데이터를 사용하세요. CSV 종목과 입력한 종목의 일치 여부는 사용자가 확인해야 합니다.

## 일봉·주봉과 종합 차트

본문 상단의 **차트 주기**를 바꾸면 같은 원본 일봉을 사용해 지표와 신호를 다시 계산합니다. 주봉의 MACD를 일봉 MACD에서 단순 추출하지 않습니다. 온라인 조회는 최근 5년이며, CSV도 주봉 분석에는 약 3년 이상의 일봉이 필요합니다.

- 주봉은 월~금의 첫 시가, 최고가, 최저가, 마지막 종가, 거래량 합계로 만듭니다. 날짜는 그 주의 금요일입니다.
- 현재 주는 해당 시장의 금요일 마감 대기 시각까지 제외합니다. 금요일 휴장 주간도 같은 기준을 적용합니다. 조회 시작이 월요일 이후인 첫 주도 보수적으로 제외합니다.
- 두 MACD(6,19,9 / 19,39,9)를 각각 선·시그널·히스토그램으로 표시합니다. 위험 경고는 기존 MACD(19,39,9)를 계속 사용합니다.
- RSI(14)는 처음 14개 가격 변화의 평균으로 시작하는 Wilder 방식입니다. 30·70 기준선을 표시하며, 상승·하락이 모두 없는 경우 50입니다.
- OBV는 첫 봉 0에서 시작합니다. 직전 종가보다 오르면 거래량을 더하고 내리면 빼며 같은 종가에서는 유지합니다. 조회 시작일이 달라지면 절대값도 달라질 수 있습니다.

기본 표시는 캔들을 읽기 쉬운 최근 60봉입니다. 가격 영역을 넓히고 오른쪽 눈금, 패널별 제목, 색상별 지표 안내, 마우스를 올린 봉의 OHLC·등락률·거래량 표시를 제공합니다. 경고 근거와 상세 분석은 접어서 볼 수 있습니다. 차트에서 드래그로 이동, 마우스 휠·도구막대로 확대, 더블클릭으로 초기화할 수 있습니다. 시간축은 패널끼리 연동되며 십자선, 선·사각형 그리기/지우기, 이미지 저장, 차트 상단 중앙의 최근 60봉·180봉·전체 버튼을 제공합니다. 날짜는 가격 차트 바로 아래와 전체 차트 하단에 표시합니다. 그린 도형은 서버에 저장하지 않으며 종목·주기 변경이나 새로고침 시 사라질 수 있습니다. TradingView 자체의 모든 기능을 구현한 것은 아닙니다.

**VRVP는 추정치입니다.** 현재 화면에 보이는 봉의 거래량을 각 봉의 고가~저가에 균등 배분하여 가격대별로 합산합니다. 차트를 확대·이동하면 표시 구간을 기준으로 다시 계산합니다. 노란 막대는 거래량이 가장 많은 추정 가격대(POC)이며 가격 구간 수는 16~64개로 바꿀 수 있습니다. 일봉·주봉 OHLCV만 사용하므로 실제 가격별 체결량, 매수·매도별 분포, TradingView의 하위 주기 기반 VRVP와는 다릅니다.

## MACD와 매도 검토 경고 기준

- MACD선 = EMA(종가, **19**) − EMA(종가, **39**)
- 시그널선 = EMA(MACD, **9**)
- 히스토그램 = MACD − 시그널
- 거래량 배율 = 최신 봉 거래량 ÷ **해당 봉을 제외한 직전 20봉 평균 거래량**

| 표시 | 발생 조건 |
|---|---|
| 주의 | MACD선이 직전 봉보다 하락하거나 시그널선 아래에 있음. 또는 거래량 증가를 동반한 종가 하락 |
| 위험 | MACD선이 최신 봉에서 시그널선을 하향 돌파(데드크로스), 0선을 하향 돌파, 또는 MACD선 하락과 거래량 증가를 동반한 종가 하락이 동시 발생 |
| 뚜렷한 하향 경고 없음 | 위 조건이 없음. 매수 추천이나 안전 보장은 아님 |

거래량 증가 기준은 **1.5배 이상**, 종가 하락은 **직전 봉 종가 대비 하락**입니다. MACD 3개 봉 연속 하락과 히스토그램 감소도 추가 설명합니다. 히스토그램 감소만으로 위험 신호를 만들지는 않습니다. 가격과 20·60·200봉 단순이동평균도 비교합니다(주봉에서는 20·60·200주, 200봉 미만에서는 200봉선 미표시).

## MACD 0선 돌파 후 오실레이터 음전환 시그널

MACD(19,39,9)가 **0 이하에서 양수로 상향 돌파**한 것을 확인한 뒤, MACD가 양수를 유지하는 동안 오실레이터(히스토그램 = MACD − 시그널선)가 **직전 봉 0 이상 → 현재 봉 음수**로 바뀌면 분홍색 ▼를 표시합니다. 가격 차트와 MACD(19,39,9) 패널의 같은 날짜에 표시하며, 마우스를 올리면 날짜와 값을 볼 수 있습니다.

- 음수가 계속되는 동안은 반복 표시하지 않습니다. 다시 0 이상으로 회복했다가 음전환하면 새 시그널을 표시합니다.
- MACD가 0 이하가 되면 조건을 초기화하고 새로운 상향 돌파를 기다립니다.
- 조회 데이터가 처음부터 MACD 양수로 시작했다면, 데이터 이전의 0선 돌파를 추정하지 않습니다. 조회 구간 안에서 확인한 돌파 이후에만 표시합니다.
- 일봉과 주봉은 각각 계산합니다. 최신 완료 봉에서 발생하면 경고 메시지를 추가하고, 과거 발생 내역은 차트 아래에서 확인합니다.
- CSV의 `MACD19SellSignal` 열은 발생 봉에서만 `True`입니다. 기존 위험 등급은 유지하며 자동 매도 주문은 실행하지 않습니다.

## 데이터 시점과 TradingView

- 분석은 Yahoo Finance의 최근 5년 일봉을 `yfinance`로 조회합니다. 온라인 조회 시 가격은 배당·분할 조정값이며 결과는 최대 15분 캐시합니다.
- 한국은 서울 시간 **16:00**, 미국은 뉴욕 시간 **17:00** 전까지 당일 일봉을 제외합니다. 미완료 일봉의 신호 변화를 줄이기 위한 보수적 기준이며, 제공처의 최종 정정까지 보장하지는 않습니다.
- 미국 서머타임을 반영합니다. 휴장일은 데이터 제공 기준이며, 미국 반일장 당일도 17:00까지 기다립니다. 화면에서 마지막 분석 날짜를 꼭 확인하세요.
- **선택한 주기의 마지막 완료 봉**을 평가합니다. 장중 실시간 감시·예약 갱신·텔레그램 알림은 아직 없습니다.
- TradingView는 외부 임베드 위젯입니다. 내부 분석 차트와 위험 신호는 Yahoo/CSV 데이터를 사용합니다. 서로 제공처·수정주가·갱신 시점·EMA 초기값이 달라 숫자가 일치하지 않을 수 있습니다.
- TradingView 위젯의 기본 MACD 설정을 바꿔도 앱의 MACD(19,39,9)에는 영향을 주지 않습니다. 이 앱의 신호는 **일봉/주봉 종합 차트** 차트에서 확인하세요.
- 위젯 표시에는 사용자의 브라우저에서 TradingView 스크립트 접근이 필요합니다. 광고 차단기나 종목 지원 제한으로 보이지 않을 수 있습니다.

## 보안·한계

계정, 증권사 API 키, 자동 주문 기능이 없습니다. 분석용 시세 조회에는 인터넷이 필요하며, TradingView 위젯은 브라우저에서 외부 서버에 연결합니다. CSV는 실행 중인 앱의 메모리에서 처리하며 앱이 원본 파일을 저장하거나 외부 AI로 전송하지 않습니다. CSV 모드의 TradingView 위젯에는 입력한 종목 정보가 전달되지만 CSV 내용은 전달하지 않습니다. 민감한 개인 자료와 인증 정보는 Git에 올리지 마세요.

이 신호는 명시한 조건을 표시하는 **규칙 기반 보조 도구**입니다. 수익성·정확도를 백테스트하지 않았으며 횡보장에서는 거짓 신호, 추세 전환에서는 지연이 발생할 수 있습니다. 데이터 오류와 접근 제한도 가능합니다. 신호만으로 매도 여부를 결정하지 마세요.

## 개발 및 검사

```bash
.venv/bin/python -m unittest discover -s tests -v
```

- `app.py`: 웹 화면, TradingView 임베드, 내부 차트

- `tests/`: 지표 계산·경고 조건·입력 검증·앱 화면 검사
- `install.ps1` / `start.ps1`: Windows 설치·실행

기능 검사와 실제 온라인 시세/외부 위젯 접근 검사는 별개입니다. 배포 환경에서 온라인 연결 여부를 확인하세요.
