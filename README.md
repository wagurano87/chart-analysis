# Chart Analysis

차트 분석 프로그램을 위한 독립 프로젝트입니다.

현재는 저장소의 기본 구조만 준비된 상태이며, 분석 프로그램은 아직 구현하지 않았습니다.

## 구성

- `README.md`: 프로젝트 소개 및 개발 상태
- `.gitignore`: Python 임시 파일, 가상환경, 인증 정보 및 로컬 분석 결과 제외

## 개발 전 결정할 사항

- 분석 대상: 주식, 가상자산 또는 다른 종류의 차트
- 입력: 가격·거래량 데이터, CSV 또는 차트 이미지
- 분석 기능과 결과 저장 형식
- 데이터 제공처 및 사용 권한

API 키, 계정 정보, 개인 거래 내역은 저장소에 커밋하지 않습니다.
