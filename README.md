Python 3.11 이상(`py` 실행기 포함)을 설치하고 저장소를 다운로드한 뒤 PowerShell에서 실행합니다.

```powershell
.\install.ps1
.\start.ps1
```

스크립트 실행 정책에 막히는 경우 현재 창에만 적용한 후 다시 실행합니다.


시작 시 표시되는 로컬 주소를 본인 브라우저에서 여세요. 기본 포트는 8501이며 `Ctrl+C`로 종료합니다. `start.ps1`은 `127.0.0.1`에만 연결하므로 같은 PC에서 사용합니다.

## 사용법

1. 데이터 방식을 선택합니다: 온라인 시세, CSV 업로드, 가상 데이터 체험.
2. 시장과 종목을 입력합니다.
   - 한국: `005930`(삼성전자), `000660`(SK하이닉스), `247540`(에코프로비엠). KOSPI/KOSDAQ을 순서대로 조회합니다.
   - 미국: `AAPL`, `NVDA`, `MSFT`, `IBM`, `BRK.B` 등.
   - 사이드바의 **종목명 / 코드 / 티커 / 코인 거래쌍** 입력칸에서 삼성전자·인텔 등의 이름을 입력하고 후보를 선택하세요. 코드와 시장이 자동 반영됩니다. 목록에 없는 종목은 입력 후 Enter로 검색하고 후보를 선택한 뒤 **분석하기**를 누르세요.
3. **분석하기**를 누릅니다. 매도 검토 경고, MACD 변화, 거래량 배율, 이동평균과 차트가 표시됩니다.
4. 필요하면 분석 결과를 CSV로 다운로드합니다.

온라인 연결이 없어도 **가상 데이터 체험**으로 기능을 확인할 수 있습니다. 가상 데이터는 실제 종목 가격이 아닙니다. CSV는 동일한 종목의 다음 열을 가진 일봉 파일이어야 합니다.

```csv
Date,Open,High,Low,Close,Volume
2026-10-20,100,105,98,103,100000
2026-10-21,103,106,101,102,150000
```

위 예시는 형식 설명이며 실제 분석에는 **선택한 주기의 완료된 봉 최소 120개**가 필요합니다. 중복 날짜, 결측값, 음수 거래량, 올바르지 않은 OHLC는 거부합니다. 일관된 수정주가 기준의 데이터를 사용하세요. CSV 종목과 입력한 종목의 일치 여부는 사용자가 확인해야 합니다.

## 일봉·주봉과 종합 차트

차트 바로 위의 **일봉·주봉 버튼**를 바꾸면 같은 원본 일봉을 사용해 지표와 신호를 다시 계산합니다. 주봉의 MACD를 일봉 MACD에서 단순 추출하지 않습니다. 온라인 조회는 최근 5년이며, CSV도 주봉 분석에는 약 3년 이상의 일봉이 필요합니다.

- 주봉은 월~금의 첫 시가, 최고가, 최저가, 마지막 종가, 거래량 합계로 만듭니다. 날짜는 그 주의 금요일입니다.
- 현재 주는 해당 시장의 금요일 마감 대기 시각까지 제외합니다. 금요일 휴장 주간도 같은 기준을 적용합니다. 조회 시작이 월요일 이후인 첫 주도 보수적으로 제외합니다.
- 두 MACD(6,19,9 / 19,39,9)를 각각 선·시그널·히스토그램으로 표시합니다. 위험 경고는 기존 MACD(19,39,9)를 계속 사용합니다.
- RSI(14)는 처음 14개 가격 변화의 평균으로 시작하는 Wilder 방식입니다. 30·70 기준선을 표시하며, 상승·하락이 모두 없는 경우 50입니다.
- OBV는 첫 봉 0에서 시작합니다. 직전 종가보다 오르면 거래량을 더하고 내리면 빼며 같은 종가에서는 유지합니다. 조회 시작일이 달라지면 절대값도 달라질 수 있습니다.

기본 표시는 캔들을 읽기 쉬운 최근 60봉입니다. 가격 영역을 넓히고 오른쪽 눈금, 패널별 제목, 색상별 지표 안내, 마우스를 올린 봉의 OHLC·등락률·거래량 표시를 제공합니다. 상세 수치와 경고 근거·사용 안내는 차트 아래에 배치해 차트를 먼저 볼 수 있습니다. 차트에서 드래그로 이동, 마우스 휠·도구막대로 확대, 더블클릭으로 초기화할 수 있습니다. 시간축은 패널끼리 연동되며 십자선, 선·사각형 그리기/지우기, 이미지 저장, 차트 상단의 최근 60봉·180봉·전체 버튼을 제공합니다. 날짜는 가격 차트 바로 아래와 전체 차트 하단에 표시합니다. 그린 도형은 서버에 저장하지 않으며 종목·주기 변경이나 새로고침 시 사라질 수 있습니다. TradingView 자체의 모든 기능을 구현한 것은 아닙니다.

- 모든 패널에 연결된 세로 십자선과 현재 패널의 가로 십자선으로 날짜·값을 확인합니다. 상단에는 선택한 봉의 OHLC·두 MACD(선/시그널/오실레이터)·RSI·OBV를 함께 표시합니다.
- 마지막 완료 봉의 종가는 점선과 오른쪽 가격표로 표시합니다. 실시간 호가가 아닙니다.
- MACD 오실레이터는 양수 증가(진한 초록), 양수 감소(연한 초록), 음수 감소(진한 빨강), 음수 증가(연한 빨강)로 구분합니다. 색상은 추가 매도 신호를 의미하지 않습니다.
- 거래량 패널의 노란 선은 해당 봉을 제외한 직전 20봉 평균입니다.
- 한글 도구막대에서 이동·구간 확대·추세선·사각형·지우기·PNG 저장을 선택합니다. MA 버튼은 이동평균선을 숨기거나 표시하고, 기본 보기는 최근 60봉 및 자동 눈금으로 복귀합니다.
- 추세선·사각형을 클릭하면 파란색으로 선택 표시됩니다. **Delete 키** 또는 **지우기 · Del** 버튼으로 선택한 도형만 삭제하고 **Esc**로 선택을 해제합니다. 방금 그린 도형은 자동 선택되므로 바로 Delete를 눌러도 됩니다. RSI 기준선·마지막 종가선은 삭제되지 않습니다. 키보드 삭제는 차트에 포커스가 있을 때만 작동합니다.
- 범위 선택·이동·확대에 맞춰 모든 지표의 시간축과 VRVP가 함께 갱신됩니다. 가격 눈금은 표시 중인 이동평균선도 포함합니다.

**VRVP는 추정치입니다.** 현재 화면에 보이는 봉의 거래량을 각 봉의 고가~저가에 균등 배분하여 가격대별로 합산합니다. 차트를 확대·이동하면 표시 구간을 기준으로 다시 계산합니다. 노란 막대는 거래량이 가장 많은 추정 가격대(POC)이며 가격 구간 수는 16~64개로 바꿀 수 있습니다. 일봉·주봉 OHLCV만 사용하므로 실제 가격별 체결량, 매수·매도별 분포, TradingView의 하위 주기 기반 VRVP와는 다릅니다.

## MACD와 매도 검토 경고 기준

- MACD선 = EMA(종가, **19**) − EMA(종가, **39**)
- 시그널선 = EMA(MACD, **9**)
- 히스토그램 = MACD − 시그널
- 거래량 배율 = 최신 봉 거래량 ÷ **해당 봉을 제외한 직전 20봉 평균 거래량**

| 표시 | 발생 조건 |
|---|---|
| 주의 | MACD선이 직전 봉보다 하락하거나 시그널선 아래에 있음. 또는 거래량 증가를 동반한 종가 하락 |
| 위험 | MACD선이 최신 봉에서 시그널선을 하향 돌파(데드크로스), 0선을 하향 돌파, 또는 MACD선 하락과 거래량 증가를 동반한 종가 하락이 동시 발생 |
| 뚜렷한 하향 경고 없음 | 위 조건이 없음. 매수 추천이나 안전 보장은 아님 |

거래량 증가 기준은 **1.5배 이상**, 종가 하락은 **직전 봉 종가 대비 하락**입니다. MACD 3개 봉 연속 하락과 히스토그램 감소도 추가 설명합니다. 히스토그램 감소만으로 위험 신호를 만들지는 않습니다. 가격과 20·60·200봉 단순이동평균도 비교합니다(주봉에서는 20·60·200주, 200봉 미만에서는 200봉선 미표시).

## MACD 0선 돌파 후 오실레이터 음전환 시그널

MACD(19,39,9)가 **0 이하에서 양수로 상향 돌파**한 것을 확인한 뒤, MACD가 양수를 유지하는 동안 오실레이터(히스토그램 = MACD − 시그널선)가 **직전 봉 0 이상 → 현재 봉 음수**로 바뀌면 분홍색 ▼를 표시합니다. 가격 차트와 MACD(19,39,9) 패널의 같은 날짜에 표시하며, 마우스를 올리면 날짜와 값을 볼 수 있습니다.

- 음수가 계속되는 동안은 반복 표시하지 않습니다. 다시 0 이상으로 회복했다가 음전환하면 새 시그널을 표시합니다.
- MACD가 0 이하가 되면 조건을 초기화하고 새로운 상향 돌파를 기다립니다.
- 조회 데이터가 처음부터 MACD 양수로 시작했다면, 데이터 이전의 0선 돌파를 추정하지 않습니다. 조회 구간 안에서 확인한 돌파 이후에만 표시합니다.
- 일봉과 주봉은 각각 계산합니다. 최신 완료 봉에서 발생하면 경고 메시지를 추가하고, 과거 발생 내역은 차트 아래에서 확인합니다.
- CSV의 `MACD19SellSignal` 열은 발생 봉에서만 `True`입니다. 기존 위험 등급은 유지하며 자동 매도 주문은 실행하지 않습니다.

## 데이터 시점과 차트

- 분석은 Yahoo Finance의 최근 5년 일봉을 `yfinance`로 조회합니다. 온라인 조회 시 가격은 배당·분할 조정값이며 결과는 최대 15분 캐시합니다.
- 한국은 서울 시간 **16:00**, 미국은 뉴욕 시간 **17:00** 전까지 당일 일봉을 제외합니다. 미완료 일봉의 신호 변화를 줄이기 위한 보수적 기준이며, 제공처의 최종 정정까지 보장하지는 않습니다.
- 미국 서머타임을 반영합니다. 휴장일은 데이터 제공 기준이며, 미국 반일장 당일도 17:00까지 기다립니다. 화면에서 마지막 분석 날짜를 꼭 확인하세요.
- **선택한 주기의 마지막 완료 봉**을 평가합니다. 장중 실시간 감시·예약 갱신·텔레그램 알림은 아직 없습니다.

## 보안·한계

계정, 증권사 API 키, 자동 주문 기능이 없습니다. 분석용 온라인 시세 조회에는 인터넷이 필요합니다. 자체 차트는 분석 데이터로 생성합니다. CSV는 실행 중인 앱의 메모리에서 처리하며 앱이 원본 파일을 저장하거나 외부 AI로 전송하지 않습니다. 민감한 개인 자료와 인증 정보는 Git에 올리지 마세요.

이 신호는 명시한 조건을 표시하는 **규칙 기반 보조 도구**입니다. 수익성·정확도를 백테스트하지 않았으며 횡보장에서는 거짓 신호, 추세 전환에서는 지연이 발생할 수 있습니다. 데이터 오류와 접근 제한도 가능합니다. 신호만으로 매도 여부를 결정하지 마세요.

### 가격 구간 측정

차트의 **측정 ↗** 버튼을 누르고 가격 패널에서 시작 가격부터 끝 가격까지 드래그합니다. 실선 테두리 사각형과 함께 시작·끝 가격, 구간 내 실제 고가·저가, 양 끝 날짜, 봉 간격, 경과 일수, `(끝 가격 / 시작 가격 − 1) × 100` 변동률을 표시합니다. 아래에서 위로 연결하면 상승률, 위에서 아래로 연결하면 하락률입니다. 클릭한 가격을 사용하며 캔들의 고가·저가에 자동으로 붙지는 않습니다. 측정선도 선택 후 Delete로 삭제할 수 있습니다.

상단의 최고가 대비 변동률은 **현재 표시 구간 최고가 → 데이터의 마지막 완료 봉 종가** 기준입니다. 과거 구간을 보고 있어도 비교 종가는 마지막 완료 봉입니다. 전체 버튼을 누르면 조회된 전체 데이터의 최고가 기준으로 계산하며, 상장 이후 전체 최고가를 뜻하지는 않습니다.

차트 위 최고·최저·비교 종가 카드 및 표시 범위·POC 텍스트는 표시하지 않습니다. VRVP와 POC 막대는 차트에 유지합니다. 차트 높이는 도구막대와 안내 줄의 실제 높이를 제외한 iframe 공간에 맞춰 내부 스크롤바가 생기지 않도록 조절합니다.

### 분기 재무 분석

온라인 시세 분석 후 하단의 **분기 재무제표 불러오기**를 누르면 매출액·영업이익을 첫 줄, 영업이익률·최신 PEG를 둘째 줄에 표시합니다. Yahoo Finance 분기 손익계산서에서 최근 최대 8분기를 가져오며 보고 통화와 결산 종료일을 표시합니다. 제공처가 4~5분기만 제공하는 종목은 8분기를 채울 수 없습니다. 없는 수치는 0으로 채우지 않으며, 데이터가 없거나 조회에 실패해도 기술적 차트는 계속 사용할 수 있습니다. 금액 그래프 단위는 보고 통화의 백만 단위입니다. 자료는 6시간 캐시합니다.

영업이익률은 영업이익/매출액×100입니다. PEG는 제공처의 최신 `trailingPegRatio` 단일 값이며, 과거 분기별 PEG는 제공하지 않습니다. 과거 PER과 일관된 성장률 자료 없이 8분기 PEG를 합성하지 않습니다. 가격 CSV와 가상 데이터에서는 실제 재무제표를 표시하지 않습니다. 테스트는 고정된 재무제표로 계산과 2열 그래프 렌더링을 검증하며 실제 제공처의 자료 가용성을 보장하지 않습니다.

ETF·펀드 등은 기업 손익계산서 대상이 아니므로 상품 유형을 먼저 확인해 별도 안내합니다. 이 경우 기업 매출액·영업이익·PEG 그래프는 제공하지 않습니다. 기업의 빈 재무 응답과 요청 실패는 각각 구분해서 안내하고, 불러오기 버튼을 다시 누르면 해당 종목의 재무 캐시를 지우고 재조회합니다. 제공처 이름은 조회 전에도 표시됩니다.

국내 종목 검색은 KRX KIND의 코스피·코스닥·코넥스 상장사 목록을 사용합니다. 앱 이용 시 마지막 성공 갱신에서 24시간이 지났으면 백그라운드 갱신합니다. 실패하면 마지막 목록을 유지하고 1시간 뒤 다음 이용 시 재시도합니다. 최초 다운로드 중에는 기본 종목만 표시하며, 화면이 열려 있으면 30초 간격으로 완료 여부를 확인해 자동 반영합니다. ‘목록 갱신 확인’으로 바로 확인할 수도 있습니다. 갱신 시각과 상태는 입력칸 아래에 표시합니다. 캐시는 `.cache/korean_listings.json`에 저장되며 서버 재배포로 삭제되면 다시 다운로드합니다. 앱이 꺼져 있는 동안 별도 예약 작업이 실행되는 방식은 아닙니다. KIND는 상장사 목록으로 ETF·ETN·모든 우선주를 포함하는 전체 증권상품 목록은 아닙니다. 기본 한글·영문 별칭과 Yahoo 검색도 함께 사용합니다. 종목 선택 후 **분석하기**를 눌러 새로 조회하세요.

온라인 시세는 가격의 0.0001% 이하인 고저가 경계 오차만 수치 오차로 보정합니다. 이를 넘는 OHLC 불일치, 결측·무한대, 비양수 가격·음수 거래량은 해당 봉을 제외하고 제외 날짜를 화면에 알립니다. 종가를 임의로 변경하거나 누락 봉을 채우지는 않습니다. 누락으로 지표가 달라질 수 있으며 최소 분석 봉 수 조건은 계속 적용됩니다. CSV의 엄격한 검증 기준은 유지됩니다.

휠 확대·축소와 드래그 이동 중에는 세로 가격·지표 눈금을 유지해 자동 재조정에 따른 크기 변화를 방지합니다. 휠은 시간축만 확대·축소합니다. **세로 맞춤**을 누르면 현재 구간에 맞춰 가격·지표 눈금을 다시 계산합니다. 최근 60봉·180봉·전체·기본 보기 버튼도 세로 눈금을 맞춥니다. 창 크기 변경은 세로 눈금을 초기화하지 않습니다.

휠은 마우스가 가리키는 날짜를 중심으로 완만하게 확대·축소하며, Shift+휠 또는 트랙패드 가로 스크롤은 기간 폭을 유지한 채 좌우로 이동합니다. 확대는 최소 10봉(데이터가 더 적으면 전체), 최대 조회 데이터와 좌우 여백 범위로 제한합니다. 연속 입력은 프레임 단위로 합치고 차트 재그리기는 순차 실행합니다. Ctrl/Command+휠은 브라우저 동작을 가로채지 않으며 차트 영역 밖에서는 페이지 스크롤을 유지합니다.

오른쪽 세로 눈금 영역 위에서 휠을 돌리면 해당 패널의 값 범위만 확대·축소합니다. 가격·거래량·두 MACD·RSI·OBV 모두 지원하며, 포인터가 가리킨 값을 중심으로 조절합니다. 시간축은 바뀌지 않습니다. **세로 맞춤** 또는 **기본 보기**로 자동 범위에 돌아갈 수 있습니다.

세로축 휠 영역은 실제 눈금 글자 크기까지 포함합니다. 오른쪽 숫자 위에 마우스를 올리면 파란 강조와 위아래 조절 커서가 나타납니다. 해당 위치에서 휠을 돌려 세로축을 조절하세요.

**이동** 도구를 선택하면 차트 안에서 상하좌우 드래그로 이동할 수 있습니다. 상하 드래그는 해당 패널의 값 범위를 이동하고, 좌우 드래그는 연동된 시간축을 이동합니다. 세로 위치는 자동으로 되돌리지 않으며 **세로 맞춤**으로 복원합니다. 추세선·사각형·측정 도구를 사용한 뒤에는 이동 버튼을 선택하세요.

오른쪽 세로 눈금의 파란 강조 영역도 직접 잡고 위아래로 드래그할 수 있습니다. 휠과 세로 눈금 드래그는 세로 확대·축소입니다. 차트 안에서 이동 도구로 드래그하면 상하좌우 위치를 옮깁니다. 드래그 도중 포인터가 눈금 영역 밖으로 나가도 버튼을 놓을 때까지 조작을 유지합니다.

## 바이낸스·업비트 코인

시장에 **바이낸스** 또는 **업비트**를 선택하고 데이터는 **온라인 시세**로 설정하세요. 바이낸스는 `BTCUSDT`, `ETHUSDT` (또는 `BTC/USDT`), 업비트는 `KRW-BTC`, `KRW-ETH`, `BTC-ETH`처럼 거래쌍을 입력한 뒤 분석하기를 누릅니다. 현물 공개 API만 사용하며 API 키·계좌 연결·주문 기능은 없습니다. 주식 이름 검색과 별개로 거래쌍은 직접 입력합니다.

바이낸스 `/api/v3/klines`, 업비트 `/v1/candles/days`에서 최대 1,500개 일봉을 페이지별 조회합니다. 중간 요청이 실패하면 일부 자료만으로 분석하지 않습니다. 거래소의 지역/IP 제한이나 상장 기간 때문에 조회가 실패하거나 데이터가 부족할 수 있습니다. 일봉·주봉 모두 기존 최소 120봉 기준을 적용합니다. 일봉 경계는 UTC 00:00(한국 09:00), 주봉은 UTC 월~일이며 완료된 봉만 분석합니다. 거래 없는 날짜는 임의로 채우지 않습니다. 거래량은 기준 코인 수량이고 가격 단위는 거래쌍의 호가 통화입니다. 코인에는 기업 재무제표·PEG를 표시하지 않습니다. 원화 이외의 환산이나 거래소 간 가격 혼합은 하지 않습니다.

바이낸스 조회는 공식 공개 시장 데이터 전용 호스트 `https://data-api.binance.vision/api/v3/klines`를 사용합니다. HTTP 403/451 접근 제한, 418/429 요청 제한, 400/404 거래쌍·요청 오류를 구분해서 표시합니다. 배포 서버의 지역/IP 정책에 따라 이 호스트도 이용이 제한될 수 있습니다. 다른 거래소나 USD 가격으로 대체하지 않습니다.

이동평균선은 **10·20·60·120·200·365봉 단순이동평균(SMA)**입니다. 일봉에서는 일 단위, 주봉에서는 주 단위로 계산합니다. 필요한 봉 수가 쌓이기 전에는 선을 표시하지 않습니다. 예를 들어 5년치 일봉으로 만든 주봉은 365주에 미달하므로 MA365가 표시되지 않을 수 있습니다. MA 버튼으로 여섯 선을 함께 표시하거나 숨깁니다. 상세 분석과 CSV에도 동일한 기간을 적용합니다.

### 코인 4시간봉

바이낸스·업비트의 온라인 시세 분석에서는 차트 위 **4시간봉**을 선택할 수 있습니다. 바이낸스 `interval=4h`, 업비트 `/candles/minutes/240`의 최대 1,500개 봉을 별도로 조회하고 모든 지표를 재계산합니다(5분 캐시). 시각은 UTC 봉 시작 시각이며 한국 시각은 +9시간입니다. 시작 시각+4시간이 현재 시각을 넘는 진행 중 봉은 제외합니다. 최소 120개 완료 봉이 필요합니다. MA365는 365개의 4시간봉입니다. 일봉 CSV·가상 데이터로 4시간봉을 생성하지 않습니다. 4시간봉 버튼 선택 시 온라인 시세 이용을 안내합니다.

### 피보나치 되돌림

**피보나치**를 선택하고 가격 차트에서 시작점→끝점으로 드래그합니다. 0·23.6·38.2·50·61.8·78.6·100% 수평선과 가격을 표시합니다. 끝점이 0%, 시작점이 100%이며 가격 = 끝 가격 + (시작 가격 − 끝 가격) × 비율입니다. 상승은 저점→고점, 하락은 고점→저점으로 그립니다. 점선 기준선의 위치를 수정하면 레벨도 갱신되며 기준선 선택 후 Delete로 전체 삭제합니다. 실제 클릭한 가격을 사용하고 고저점에 자동으로 맞추지는 않습니다. 도형은 새로고침·주기 변경 시 사라질 수 있습니다.

4시간봉 버튼은 모든 시장에서 표시합니다. 온라인 주식은 최근 1년의 1시간봉을 거래소 현지 정규장 개장 시각(한국 09:00, 미국 09:30)부터 4시간 단위로 합산합니다. 정규장 마지막 봉은 짧을 수 있습니다. 미국 서머타임을 반영하며 당일 자료는 한국 16시·미국 17시 이후에 사용합니다. 제공처의 시간봉 지원 여부와 데이터 양에 따라 조회가 제한될 수 있습니다. 피보나치 되돌림 버튼은 차트 상단의 별도 도구 줄에 표시됩니다.

모바일에서는 **이동** 도구에서 두 손가락을 벌리거나 모아 시간축과 터치한 패널의 세로 범위를 함께 확대·축소할 수 있습니다. 두 손가락의 중심을 기준으로 조절합니다. 한 손가락은 페이지 스크롤에 사용합니다. 그리기 도구에서는 기존 그리기 동작을 유지하므로 핀치 전에 이동을 선택하세요.

모바일에서는 **도형 선택** 목록에서 원하는 피보나치·측정·추세선·사각형을 고르고 **선택 삭제**를 누릅니다. **도형 전체 삭제**는 사용자 도형과 연결된 레벨 표시만 삭제하며 기본 지표·종가선은 유지합니다. 그리기는 한 번 완료하면 자동으로 이동 모드로 돌아옵니다. 피보나치 버튼도 실제 선택 상태일 때만 강조됩니다.

화면 상단의 **₿ 비트코인 / ◆ 이더리움** 버튼은 바이낸스 현물 `BTCUSDT` / `ETHUSDT`를 즉시 분석합니다. 시장·데이터 방식·거래쌍도 함께 바뀌며 현재 선택한 일봉·주봉·4시간봉은 유지합니다. 별도로 분석하기를 누를 필요가 없습니다.

## ADXR ADX and DI

OBV 아래 패널에 +DI(초록), −DI(빨강), ADX(노랑), ADXR(보라)를 표시합니다. 사이드바 설정 기본값은 Length 14, Threshold 20, Length ADX 14, Length ADXR 14입니다. Wilder RMA는 첫 기간의 단순평균으로 시작하며, 첫 TR은 고가−저가, 첫 DM은 0입니다. DI는 평활 DM/TR×100, DX는 |+DI−−DI|/(+DI+−DI)×100, ADX는 DX의 RMA, ADXR은 (현재 ADX + ADXR 기간 전 ADX)/2입니다. 0으로 나누는 평탄 구간은 0, 준비 기간은 결측으로 표시합니다. 기준선은 표시용이고 매도 경고 조건은 바꾸지 않습니다. 사진의 TradingView 스크립트 원본은 확인되지 않아 초기값·ADXR 지연 방식 등에 따라 수치가 다를 수 있습니다.


미국 종목은 Nasdaq Trader의 `nasdaqlisted.txt`와 `otherlisted.txt` 공개 목록을 사용합니다. NASDAQ·NYSE·NYSE American·NYSE Arca·Cboe BZX·IEX의 목록에 수록된 종목과 ETF를 검색하며, 테스트 종목 및 시세 제공처와 표기가 호환되지 않는 일부 특수 증권은 제외합니다. OTC 비상장·장외 종목은 포함하지 않습니다. 영문 회사명과 티커로 검색하고, 기본 목록에 등록된 한글 별칭도 사용할 수 있습니다. 모든 미국 회사명의 한글 번역을 제공하는 것은 아닙니다.

국내 목록과 마찬가지로 24시간마다 백그라운드 갱신하며 실패 시 마지막 목록을 유지하고 1시간 후 재시도합니다. 앱이 열려 있는 동안 상태를 확인하며, 앱이 중지되어 있으면 다음 이용 시 갱신합니다. 캐시 파일은 `.cache/us_listings.json`이며 갱신 상태와 한국 시간 기준 갱신 시각을 입력칸 아래에 표시합니다.

+DI가 −DI를 상향 돌파한 완료 봉(직전 +DI ≤ −DI, 현재 +DI > −DI)에 초록색 ▲ 매수 시그널을 가격·DI 패널에 표시합니다. 일봉·주봉·4시간봉의 선택 주기를 따르며 ADX 임계값 조건은 추가하지 않습니다. 초기 지표 미계산 구간 및 +DI 우위가 이어지는 봉에는 반복 표시하지 않습니다.

### 코인 10초 자동 갱신

온라인 바이낸스·업비트 분석에서 `코인 10초 자동 갱신`을 기본으로 켭니다. 일봉·주봉·4시간봉을 지원합니다. Streamlit의 10초 fragment가 최근 30개 일봉 또는 4시간봉을 받아 기존 이력과 합치고, 화면을 재실행하지 않고 기존 차트에 데이터를 전달합니다. 일봉으로 주봉을 합산하며 현재 미완료 주도 표시합니다. 초기 전체 이력과 지표 계산을 위한 이전 봉은 유지합니다.

- 진행 중인 봉의 OHLCV·이동평균·지표·VRVP를 갱신합니다. +DI 매수 및 MACD 매도 표시는 완료된 봉에서만 확정합니다.
- 가격·시간축 확대 위치, 이동평균 표시 상태, 사용자 도형을 유지합니다. 최신 봉을 보고 있을 때 새 봉이 추가되면 시간축도 한 봉 따라갑니다. 과거 구간을 보고 있으면 이동하지 않습니다.
- 차트 안의 마지막 가격과 수신 시각을 확인하세요. 차트 밖 요약·신호 내역·다운로드 CSV는 분석하기를 누른 시점 기준이며 자동 갱신 대상으로 혼동하지 않도록 안내합니다.
- 자동 갱신을 끄거나 종목·주기를 바꾸는 앱 재실행은 차트를 다시 만들 수 있습니다. 도형을 영구 저장하는 기능은 아닙니다.
- 연결 실패 시 마지막 수신 차트를 유지하고 상태를 표시합니다. 조회 공백이 너무 길면 분석하기로 다시 불러오세요. 거래소가 봉을 갱신하는 시점·네트워크 지연에 따라 화면 반영이 늦어질 수 있습니다.
- 별도 실시간 시세 서버나 API 키 없이 기존 Streamlit 서버에서 공개 시세를 조회합니다. 세션마다 요청하므로 동시 사용자가 많으면 요청 공유·캐시 구조가 추가로 필요합니다. 주식 실시간 조회 및 푸시 알림은 포함하지 않습니다.
