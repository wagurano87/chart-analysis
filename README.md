# Chart Analysis

한국·미국 주식 종목을 입력하면 TradingView 차트와 **MACD(19,39,9), 거래량, 이동평균**을 보여주는 Python/Streamlit 웹앱입니다. 브라우저로 사용하며 자동 매매나 증권 계좌 연결은 하지 않습니다.

## Windows 설치·실행

Python 3.11 이상(`py` 실행기 포함)을 설치하고 저장소를 다운로드한 뒤 PowerShell에서 실행합니다.

```powershell
.\install.ps1
.\start.ps1
```

스크립트 실행 정책에 막히는 경우 현재 창에만 적용한 후 다시 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

시작 시 표시되는 로컬 주소를 본인 브라우저에서 여세요. 기본 포트는 8501이며 `Ctrl+C`로 종료합니다. `start.ps1`은 `127.0.0.1`에만 연결하므로 같은 PC에서 사용합니다.

### Linux / macOS

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

## 사용법

1. 데이터 방식을 선택합니다: 온라인 시세, CSV 업로드, 가상 데이터 체험.
2. 시장과 종목을 입력합니다.
   - 한국: `005930`(삼성전자), `000660`(SK하이닉스), `247540`(에코프로비엠). KOSPI/KOSDAQ을 순서대로 조회합니다.
   - 미국: `AAPL`, `NVDA`, `MSFT`, `IBM`, `BRK.B` 등. TradingView용 거래소도 정확히 선택하세요. 예: IBM은 NYSE.
   - 회사명 검색은 아직 지원하지 않습니다.
3. **분석하기**를 누릅니다. 매도 검토 경고, MACD 변화, 거래량 배율, 이동평균과 차트가 표시됩니다.
4. 필요하면 분석 결과를 CSV로 다운로드합니다.

온라인 연결이 없어도 **가상 데이터 체험**으로 기능을 확인할 수 있습니다. 가상 데이터는 실제 종목 가격이 아닙니다. CSV는 동일한 종목의 다음 열을 가진 일봉 파일이어야 합니다.

```csv
Date,Open,High,Low,Close,Volume
2026-10-20,100,105,98,103,100000
2026-10-21,103,106,101,102,150000
```

위 예시는 형식 설명이며 실제 분석에는 **완료된 일봉 최소 120개**가 필요합니다. 중복 날짜, 결측값, 음수 거래량, 올바르지 않은 OHLC는 거부합니다. 일관된 수정주가 기준의 데이터를 사용하세요. CSV 종목과 입력한 종목의 일치 여부는 사용자가 확인해야 합니다.

## MACD와 매도 검토 경고 기준

- MACD선 = EMA(종가, **19**) − EMA(종가, **39**)
- 시그널선 = EMA(MACD, **9**)
- 히스토그램 = MACD − 시그널
- 거래량 배율 = 당일 거래량 ÷ **당일을 제외한 직전 20거래일 평균 거래량**

| 표시 | 발생 조건 |
|---|---|
| 주의 | MACD선이 직전 일봉보다 하락하거나 시그널선 아래에 있음. 또는 거래량 증가를 동반한 종가 하락 |
| 위험 | MACD선이 당일 시그널선을 하향 돌파(데드크로스), 0선을 하향 돌파, 또는 MACD선 하락과 거래량 증가를 동반한 종가 하락이 동시 발생 |
| 뚜렷한 하향 경고 없음 | 위 조건이 없음. 매수 추천이나 안전 보장은 아님 |

거래량 증가 기준은 **1.5배 이상**, 종가 하락은 **전일 종가 대비 하락**입니다. MACD 3거래일 연속 하락과 히스토그램 감소도 추가 설명합니다. 히스토그램 감소만으로 위험 신호를 만들지는 않습니다. 가격과 20·60·200일 단순이동평균도 비교합니다(200일 미만 데이터는 200일선 미표시).

## 데이터 시점과 TradingView

- 분석은 Yahoo Finance의 최근 2년 일봉을 `yfinance`로 조회합니다. 온라인 조회 시 가격은 배당·분할 조정값이며 결과는 최대 15분 캐시합니다.
- 한국은 서울 시간 **16:00**, 미국은 뉴욕 시간 **17:00** 전까지 당일 일봉을 제외합니다. 미완료 일봉의 신호 변화를 줄이기 위한 보수적 기준이며, 제공처의 최종 정정까지 보장하지는 않습니다.
- 미국 서머타임을 반영합니다. 휴장일은 데이터 제공 기준이며, 미국 반일장 당일도 17:00까지 기다립니다. 화면에서 마지막 분석 날짜를 꼭 확인하세요.
- **분석하기를 누른 시점의 마지막 일봉**을 평가합니다. 장중 실시간 감시·예약 갱신·텔레그램 알림은 아직 없습니다.
- TradingView는 외부 임베드 위젯입니다. 내부 분석 차트와 위험 신호는 Yahoo/CSV 데이터를 사용합니다. 서로 제공처·수정주가·갱신 시점·EMA 초기값이 달라 숫자가 일치하지 않을 수 있습니다.
- TradingView 위젯의 기본 MACD 설정을 바꿔도 앱의 MACD(19,39,9)에는 영향을 주지 않습니다. 이 앱의 신호는 **분석에 사용한 일봉 · MACD · 거래량** 차트에서 확인하세요.
- 위젯 표시에는 사용자의 브라우저에서 TradingView 스크립트 접근이 필요합니다. 광고 차단기나 종목 지원 제한으로 보이지 않을 수 있습니다.

## 보안·한계

계정, 증권사 API 키, 자동 주문 기능이 없습니다. 분석용 시세 조회에는 인터넷이 필요하며, TradingView 위젯은 브라우저에서 외부 서버에 연결합니다. CSV는 실행 중인 앱의 메모리에서 처리하며 앱이 원본 파일을 저장하거나 외부 AI로 전송하지 않습니다. CSV 모드의 TradingView 위젯에는 입력한 종목 정보가 전달되지만 CSV 내용은 전달하지 않습니다. 민감한 개인 자료와 인증 정보는 Git에 올리지 마세요.

이 신호는 명시한 조건을 표시하는 **규칙 기반 보조 도구**입니다. 수익성·정확도를 백테스트하지 않았으며 횡보장에서는 거짓 신호, 추세 전환에서는 지연이 발생할 수 있습니다. 데이터 오류와 접근 제한도 가능합니다. 신호만으로 매도 여부를 결정하지 마세요.

## 개발 및 검사

```bash
.venv/bin/python -m unittest discover -s tests -v
```

- `app.py`: 웹 화면, TradingView 임베드, 내부 차트
- `analysis.py`: 데이터 검증, 완료 일봉 필터, MACD·거래량·위험 규칙
- `data.py`: 종목코드 처리, Yahoo 조회, CSV 읽기, 가상 데이터
- `tests/`: 지표 계산·경고 조건·입력 검증·앱 화면 검사
- `install.ps1` / `start.ps1`: Windows 설치·실행

기능 검사와 실제 온라인 시세/외부 위젯 접근 검사는 별개입니다. 배포 환경에서 온라인 연결 여부를 확인하세요.
